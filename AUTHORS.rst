Authors and contributions
=========================

Human contributions
-------------------

* Xinyu Nie: author of the superficial white matter tracking algorithm and
  its original algorithm code; first author of the surface-based probabilistic
  tracking paper; SurfTracker project maintainer.
* Yonggang Shi: gyral/sulcal segmentation and Hamilton-Jacobi skeleton code
  and methodological foundation used by the pipeline; principal investigator
  of the Neuro Image Computing Research (NICR) group.
* Jialiang Ruan: contributions to the C++ implementation of the tracking code.
  This historical implementation credit is retained separately from authorship
  of the current Python source files.

These roles were supplied by Xinyu Nie during release preparation. The current
Python package was prepared with AI-assisted development and human-directed
numerical/cohort validation. Scientific and implementation differences from the
publications are documented in docs/preprocessing.rst and docs/validation.rst.
