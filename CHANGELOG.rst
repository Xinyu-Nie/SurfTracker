SurfTracker downloads
=====================

0.3.0.dev18
-----------

* Distribute a compiled Linux x86_64 / CPython 3.12 wheel and a complete binary kit.
* Preserve the swmtrack command, Python interfaces and recommended scientific
  settings. Core scientific modules are compiled and source is maintained privately.
* Validate installed binaries, API metadata, deterministic sampling, seeded
  tracking, fresh FreeSurfer/FOD workflows and artifact contents.
* Record native implementation identities in caches and workflow checkpoints.
* Provide user documentation, synthetic/QC helpers, checksums and download CI
  in the public main branch. Remove source-build and source-upload workflows.

Earlier public revisions remain in repository history. Historical branch tips
are preserved. This update does not upload a package to PyPI or TestPyPI.
