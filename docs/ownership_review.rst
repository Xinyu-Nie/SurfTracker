Copyright-holder determination
==============================

Status: unresolved; no ownership assignment or active license grant is made here.

USC's March 2026 policy, sections 3.1--3.2, provides institutional ownership rules
for employment, sponsored work and significant resource use, with background-IP,
scholarly-work and student exceptions. Sections 4.3 and 4.5 address notices and
consultation with USC Stevens before distribution. Section 7 addresses execution
of USC agreements. Applying those rules requires this project's actual facts.

If USC ownership is confirmed, its prescribed holder name is University of
Southern California. NICR and the institute are credited as affiliations. An
individual holder, as shown in Trekker's notice, cannot be inferred for this
project by analogy. First-publication year and any pre-existing code rights
also need to match the actual code covered.

Source: USC Intellectual Property Policy, effective March 1, 2026:
https://stevens.usc.edu/wp-content/uploads/2026/02/FINAL-2026-USC-INTELLECTUAL-PROPERTY-POLICY_2-23-26.pdf .

USC Stevens Center for Innovation, the IP/licensing office, is distinct from the
Mark and Mary Stevens Neuroimaging and Informatics Institute, the research
institute. A short ownership/license clarification worksheet is in the local
licensing/ folder for the maintainers to use if needed.
